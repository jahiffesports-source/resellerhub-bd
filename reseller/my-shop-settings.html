Server-side endpoint (optional)

Meta Conversions API-এর মতো server-side tracking-এর জন্য আপনার নিজস্ব endpoint দিন (যেমন https://yoursite.com/capi.php)। খালি রাখলে শুধু browser pixel ব্যবহার হবে।

Browser pixel ID সবসময় page source-এ দৃশ্যমান হয় — এটি Facebook/TikTok-এর নিজস্ব নিয়ম। Token/secret-এর মতো গোপন তথ্য এখানে রাখবেন না; সেই কাজের জন্য উপরের server-side endpoint ব্যবহার করুন (credentials সেখানে server-এ থাকে)।

Connect Custom Domain

আপনার নিজের domain যুক্ত করুন — যেমন www.mybusiness.com বা shop.mybusiness.com।

১. আপনার DNS provider-এ নিচের TXT record যোগ করুন, তারপর Verify DNS চাপুন।

২. Verification সফল হলে domain activate হবে। এরপর নিচের CNAME/A record দিয়ে traffic পাঠান।

SSL/HTTPS: custom domain-এ HTTPS চালু করতে হবে আপনার hosting/CDN-এ (যেমন Cloudflare-এর free SSL)। এই অ্যাপটি শুধু চেক করে page HTTPS-এ load হয়েছে কি না — —
