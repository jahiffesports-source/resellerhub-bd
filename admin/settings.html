যে কুরিয়ার দিয়ে অর্ডার পাঠাবেন সেটা বেছে নিন। প্রতিটি কুরিয়ারের API Key আলাদা করে সেভ হয় — একটার key অন্যটায় যায় না। Orders পেজের "Book Selected" বাটন এই বেছে নেওয়া কুরিয়ারেই বুক করবে।
ফোল্ডারের backend/steadfast-proxy.php ফাইলটা আপনার hosting-এ আপলোড করে ওই URL বসান। এতে API key ব্রাউজারে দেখা যাবে না এবং CORS সমস্যাও থাকবে না। খালি রাখলে সরাসরি (direct) API call হবে।
কুরিয়ার (Steadfast) অ্যাকাউন্টের Shop ID। এই একটা আইডি-ই প্রতিটা প্রিন্ট-এ বসবে — সাপ্লায়ারের Ready-to-Ship ইনভয়েস, অ্যাডমিনের All Orders ইনভয়েস আর Multi-Supplier ইনভয়েস, সবখানে। খালি রাখলে ডিফল্ট OGIQVRWD দেখাবে।

Fraud Check (Test)

কাস্টমারের phone দিয়ে Steadfast delivery history চেক করুন — কতগুলো সফল ডেলিভারি, কতগুলো cancel।

কীভাবে কাজ করে

১. Steadfast portal (portal.steadfast.com.bd) → Apps/API থেকে API Key ও Secret Key নিন।
২. উপরে সেভ করুন — তারপর Orders পেজে গিয়ে একাধিক order checkbox সিলেক্ট করে "Book Selected → Steadfast" চাপলেই সব অর্ডার একসাথে বুক হয়ে যাবে (tracking code অটো অর্ডারে বসবে)।
৩. যেকোনো order ভিউ করে 🛡 Fraud Check চাপলে ওই কাস্টমারের Steadfast delivery history দেখা যাবে।
⚠️ ব্রাউজার থেকে সরাসরি API call করলে CORS block হতে পারে — তখন CORS-unblock extension লাগবে অথবা Steadfast-এ domain whitelist করতে হবে।

My Shop Default Banner

এখানে ৩টি পর্যন্ত ব্যানার আপলোড করলে সেটি প্রতিটি রিসেলারের My Shop-এ ডিফল্ট হিসেবে দেখাবে — হোমপেজের উপরে, পুরো চওড়া, প্রতি ২ সেকেন্ডে একটার পর একটা বদলাবে।
রিসেলার তার নিজের Shop Settings থেকে এগুলো দেখতে পাবে, চাইলে মুছে নিজের ব্যানার দিতে পারবে, আর “Reset to Default” চাপলে আবার এই ব্যানারগুলোই ফিরে আসবে।
ব্যানারটি ON/OFF করার সুইচ রিসেলারের নিজের হাতে — ডিফল্টভাবে চালু থাকে।

My Shop Default Homepage

এখানে যে ব্লকগুলো বানাবেন সেটি প্রতিটি রিসেলারের My Shop হোমপেজ-এ ডিফল্ট হিসেবে দেখাবে। রিসেলার তার নিজের Shop Settings → Homepage Sections থেকে এগুলো দেখতে পাবে, চাইলে বদলাতে বা মুছতে পারবে, আর “Reset to Default” চাপলে আবার এগুলোই ফিরে আসবে।
পরামর্শ: ব্লকে নির্দিষ্ট প্রোডাক্ট না বেছে শুধু ক্যাটাগরি দিলে প্রতিটি রিসেলারের শপে সেই ক্যাটাগরির তার নিজের প্রোডাক্টগুলোই দেখাবে — এটাই সবচেয়ে নিরাপদ ডিফল্ট।
